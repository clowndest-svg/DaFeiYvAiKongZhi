# 小知（BiZhi）· 本地 AI 女友与多平台账号控制台

**一个跑在你自己电脑上的 AI 伴侣**：网页和 QQ 都能聊天，有长期记忆、情绪、日记和自己的作息；她还能替你打理 QQ 空间、小红书、X（推特）和抖音——每一次动手都有开关、限额、回执和可查的日志。纯 Node.js，无编译步骤，数据只存在本机。

> 安全说明：本仓库不包含任何人的 API Key、QQ 号、服务器地址或私人信件。所有密钥与账号配置都放在被 git 忽略的 `.env` 与 `data/` 里，由你自己填写。

## 1. 项目简介

- **一个角色**：默认叫小知，人设写在 `config/persona.md`（可用 `BIZHI_PERSONA_FILE` 换成你自己的私有文件），说话方式、喜好和边界都可以直接改。
- **一套记忆**：近期对话自动压缩 → 重点记忆（事后反思抽取，必须带你的原话作证据）→ 长期周记与交接信。她还能自己写、自己改「给自己看的话」（自我档案）。
- **一个生活**：心情、神经递质底座、拟人遗忘曲线、感官记忆、主动找你、写日记和周记。
- **一个运营助手**：QQ 空间、小红书、X、抖音的登录、浏览、评论、回复、发布，全部在控制台里操作；每次外部动作都有真实回执，确认不了就标"结果未知"，绝不盲目重发。
- **一套可视化**：控制台「日志」页能看到她的内心独白、自我档案、运行事件和服务日志。

**GitHub 仓库简介（About 栏可直接用）**：
> 本地运行的 AI 女友与多平台账号控制台：网页/QQ 聊天、长期记忆与自我档案、主动陪伴、语音、联网搜索，以及带审批与风控的 QQ 空间 / 小红书 / X / 抖音运营。纯 Node.js，一条命令起步，数据只存本机。

技术栈：Node.js 22.16+（推荐 24 LTS）、原生 `node:sqlite`、原生 HTTP/WebSocket、无前端构建（`web/` 是原生 HTML/CSS/JS）、OpenAI 兼容的聊天接口（默认 DeepSeek）、Playwright 用于测试。

## 3. 一键部署（新手推荐）

前置：Windows 10/11 + 安装 [Node.js 24 LTS](https://nodejs.org/)（最低 22.16）。

1. 下载或克隆本仓库，解压到任意目录（**路径尽量不含中文**）。
2. 双击 **`setup.bat`**。它会自动：
   - 检查 Node 版本；
   - 安装依赖（`npm ci`）；
   - 交互生成 `.env`（DeepSeek API Key、控制台密码、随机 OneBot 令牌、QQ 接入端）；
   - 询问是否立即启动。
3. 浏览器打开 `http://127.0.0.1:7788/`，输入你刚设的控制台密码。

之后每次启动：双击 `run.bat`（前台）或 `start-bizhi-hidden.vbs`（后台无窗口）。

> 只填 API Key 也能开始聊网页；QQ、小红书、X、抖音都是可选接入，在设置页按提示扫码。

## 4. 手动安装

```bash
npm ci
copy .env.example .env        # Windows；Linux/macOS 用 cp
# 编辑 .env，至少填写 DEEPSEEK_API_KEY 和 CONSOLE_PASSWORD
npm start
```

运行要求：Node.js 22.16+。QQ 接入、语音合成（SAPI）和后台守护在 Windows 上最完整；Linux/macOS 可运行聊天与网页部分。

## 5. 第一次打开会看到什么

左侧导航六个页面：

- **聊天**：对话、停止、发图片。
- **陪伴**：立绘 + 摄像头/麦克风/语音（默认关闭，需要逐项打开）。
- **记忆**：重点记忆、日记、信；可以手动加记忆、更正记忆。
- **动态**：内容创作（让她写一条 / AI 资讯选题 / 评论区替她说话）→ 平台互动（空间 / 小红书私信 / 小红书图文）→ 生产与记录（视频任务 / 动态记录 / 待处理 / 今日费用）。
- **日志**：她写给自己的话、最近 30 条内心独白、运行事件、服务日志尾巴。
- **设置**：按功能分区。**平台的登录、开关和自动行为都在设置里按平台分区**（QQ / 小红书 / X / 抖音）。

## 6. 配置详解（.env）

在项目根目录 `.env`（从 `.env.example` 复制，已被 git 忽略）：

| 变量 | 必填 | 说明 |
|---|---|---|
| `DEEPSEEK_API_KEY` | ✅ | 聊天接口密钥（DeepSeek 或任何 OpenAI 兼容服务商的 Key，见第 9 节） |
| `DEEPSEEK_BASE_URL` | | 接口地址，默认 `https://api.deepseek.com`；也可以在控制台里改 |
| `DEEPSEEK_MODEL` | | 默认模型名，默认 `deepseek-flash`；控制台可覆盖 |
| `PORT` | | 控制台端口，默认 `7788` |
| `CONSOLE_PASSWORD` | ✅ | 控制台登录密码；外网访问必须设强密码并配 HTTPS |
| `ONEBOT_TOKEN` | 接 QQ 时 | 与 QQ 接入端约定的随机字符串；`setup.bat` 会自动生成 |
| `BIZHI_QQ_PROVIDER` | | QQ 接入端：`snowluma`（本项目实机验证与推荐）或 `napcat`（兼容备选）；改完需重启 |
| `X_PROXY_URL` | 用 X 时 | 本机代理地址，默认 `http://127.0.0.1:7897`；X 在国内直连不通 |
| `BIZHI_DOUYIN_REPLY_ENABLED` | 抖音真发时 | `1` 才允许真实发送评论；默认关闭，只起草不发出 |
| `BIZHI_PERSONA_FILE` | | 私有角色文件路径（不想改仓库里的 `config/persona.md` 时用） |
| `BIZHI_MOM_LETTER_FILE` | | 「妈妈的信」路径；仓库自带的 `config/mom-letter.md` 是空模板，写你自己的放这里 |
| `BIZHI_DATA_DIR` | | 数据目录，默认项目下 `data/`；想放别的盘就指这里 |
| `CHROME_PATH` | | 指定 Chrome/Edge 路径（自动探测失败时用） |
| `OPEN_BROWSER` | | `1` 启动时自动打开控制台 |
| `QZONE_BRIDGE_URL` / `QZONE_BRIDGE_TOKEN` | 可选 | 用外部桥发空间说说时用，一般不用 |
| `BIZHI_PRICING_JSON` | 可选 | 自定义费率（本地台账估算用，不是平台账单） |

密钥安全：`.env`、`config/settings.json`、`data/` 都在 `.gitignore` 里；日志里的密钥会自动打码。

## 7. 接入 QQ（SnowLuma / NapCat）

QQ 是可选通道，不接也能用网页聊天。**本项目实机验证与默认配置使用 SnowLuma。**

### SnowLuma（推荐）

1. 从 SnowLuma 官方发布页下载 Windows 发行包，解压到项目下的 `snowluma/` 目录（该目录不提交）。
2. 在 `.env` 确认 `BIZHI_QQ_PROVIDER=snowluma`（`setup.bat` 默认就是）。
3. 启动后打开控制台 → 设置 →「QQ 连接与行为」→ 按提示在桌面 QQ 里扫码登录**机器人小号**，再在 SnowLuma 本机管理页（默认 `http://127.0.0.1:5099/`）手动接入该 QQ 进程；**不要启用自动注入**。
4. 控制台会分别显示：通道连没连上、账号在不在线（探不到就写"未确认"）、最近 7 天断线情况。

### NapCat（兼容备选）

1. 从 [NapCatQQ 发布页](https://github.com/NapNeko/NapCatQQ/releases) 下载与 QQ 版本匹配的包，解压到 `napcat/`（不提交）。
2. 配置 OneBot v11 反向 WebSocket：`ws://127.0.0.1:7788/onebot`，令牌与 `ONEBOT_TOKEN` 一致。
3. 设置 `BIZHI_QQ_PROVIDER=napcat`，重启服务；在控制台扫码登录小号。

> 程序不会自动杀 QQ 进程（杀进程会把登录踢掉）。掉线时协议端会自己重连；只有"开机很久没连上且确认进程不在"才尝试拉起一次。
> 风险提示：个人 QQ 号跑协议端有平台规则和封号风险，只用专用小号，不群发、不高频互动。

### 小号怎么工作

- 机器人只登**小号**；大号（主人）私聊她才会以女朋友身份回复，陌生人私聊/群聊按设置与隐私边界处理。
- 首次接入后在设置里确认主人身份，别把主号当机器人号扫码。

## 8. 接入小红书 / X / 抖音 / QQ 空间

所有平台都用**专用浏览器 + 扫码登录**，不保存密码；登录态存在本机 `data/` 下。入口统一在**设置页对应分区**。

### 小红书（设置 → 小红书）

- 「打开登录窗口」→ 专用 Chrome 扫码；「验证登录」确认状态。
- 自动行为开关：浏览并评论、回自己笔记评论、点赞、收藏、自动发布、私信。
- 私信自动回复前，先在私信列表点「确认这个会话是我」建立绑定。
- 每天/每小时/总动作都有上限；遇到验证页自动停 6 小时并写事件。

### X / 推特（设置 → X / 推特）

- 必须配置本机代理（`X_PROXY_URL`）。登录窗口不带自动化标记；登完点「验证登录」。
- 「让她起草一条」只填进编辑器；「发布填好的那条」才会真发，且只发逐字核对过、15 分钟内填的那条。

### 抖音（设置 → 抖音）

- 「显示登录页面」→ 扫码；「读取我的作品」完成账号绑定。
- 评论回复：读评论 → 生成回复 → 填进后台草稿 → 你点「确认发送」。发送前核对视频、楼层、对象、内容和按钮五处；回执确认不了就标"结果未知"，绝不盲目重发。
- 真实发送默认关闭：需要 `.env` 设 `BIZHI_DOUYIN_REPLY_ENABLED=1`，建议先在评论区亲手验收一条。
- 自动刷视频：打开视频页采两帧画面 + 标题简介交给视觉模型生成理解笔记（声音不接入），每半小时一条、每天最多 6 条。

### QQ 空间

- 设置 →「动态与空间」配置后，动态页「空间互动」可读说说/评论、有限额回复、发文字说说。Cookie 必须属于设置里的机器人号。

## 9. 更换大模型接口

可以。控制台 **设置 →「聊天与记忆」→ 模型** 里有三个字段：

- **模型**：内置 `deepseek-flash` / `deepseek-v4-pro` 两个常用项。
- **自定义模型名**：换其他服务商时填这里（例如 `gpt-4.1-mini`、`qwen-plus`），优先于上面的选择。
- **接口地址**：任何 **OpenAI 兼容**的 `/v1` 地址（例如 `https://api.moonshot.cn/v1`）；留空用 `.env` 的 `DEEPSEEK_BASE_URL`。

API Key 仍写在 `.env` 的 `DEEPSEEK_API_KEY`（控制台不保存密钥）。改完点 **「测试连接」** 会发一次最小请求验证（会花一点钱）；保存后**不用重启**即刻生效。

**换服务商后会发生什么（如实说明）**：

| 能力 | 换成非 DeepSeek 服务商后 |
|---|---|
| 聊天、记忆、反思、语音 | 正常（只要是 OpenAI 兼容的 `/chat/completions`） |
| 联网搜索 | DeepSeek 官方搜索/读页接口不可用，自动退回免 key 的 Bing/搜狗抓取（只有摘要、没有正文，质量下降） |
| 余额显示 | 查不到，显示"未读数"（不假装有钱） |
| 费用台账 | 按旧模型的费率估算（标"估算"，不是账单） |
| 图片理解（抖音刷视频的视觉理解、QQ 发图） | 取决于你换的模型是否支持图片输入；不支持时她把图当看不见，如实说读不到 |
| 提示词缓存折扣 | 取决于服务商是否提供，DeepSeek 的自动缓存（约 35–48% 命中）在别家不保证 |

模型对比和挑选建议见 `docs/` 下的实测记录；不确定就先点「测试连接」。

## 10. 她的人格、记忆与「自己写的话」

- **人设**：`config/persona.md`，改完立即生效；私有角色用 `BIZHI_PERSONA_FILE` 指定自己的文件（不进仓库）。
- **三层记忆**：近期对话（自动压缩）→ 重点记忆（反思抽取，必须带你的原话作证据）→ 长期周记/交接信。
- **自我档案**：她在事后反思时可以**追加或整段重写「她自己写的话」**，注入时优先级高于普通说话参考；你可以在「日志」页查看、一键清空。
- **说话边界**：表达方式由她自己把握；三条底线不变——只用有记录的事实（不许编造搜索结果）、私密信息留在私聊、你说停就停。
- **手动修正**：记忆页可以加记忆、更正记忆；公开内容发出前都过隐私检查。

## 11. 日志、数据与隐私

| 内容 | 位置 |
|---|---|
| 数据库（聊天、记忆、事件、费用） | `data/bizhi.db`（SQLite，自动备份保留 7 份） |
| 应用日志（每天一份，保留 14 天，自动脱敏） | `data/logs/app-YYYY-MM-DD.log` |
| 进程输出 | `data/logs/server.out` |
| 她的内心独白 | 挂在每条回复的 meta 里；控制台「日志」页查看 |
| 日记 / 周记 / 交接信 | `data/daily` / `data/weekly` / `data/letters` |
| 小红书 / X / 抖音登录态 | `data/xhs-profile` / `data/x-profile` / `data/douyin-profile` |
| 公开配图素材 | `data/public-media/`（只有这里和内置素材会被选为配图） |

- 服务只监听 `127.0.0.1`。外网使用请走 **HTTPS 隧道**并设置强密码；不要把协议端 WebUI、Chrome 调试端口暴露到公网。
- 摄像头/麦克风只在陪伴页打开时采集，录音在本机识别。
- 聊天和图片会发给你配置的模型服务商（默认 DeepSeek）；在线语音合成会发给微软。除此之外的数据不出本机。
- 本仓库不附带任何真实 API Key、QQ 号、服务器地址或私人信件；`config/mom-letter.md` 是空模板。

| `npm run smoke -- --confirm-cost` | 在线模型冒烟测试（会花钱） |
| `npm run tts:install-local` | 下载本地离线音色（约 130MB，仅本机自用，注意模型许可） |

## 13. 测试与验收

- 测试全部跑在隔离目录（独立 data/settings/persona、模拟模型、本地 HTTP/WS 夹具），**不会碰真实数据或真实进程**。
- 规模：单元/契约 630+ 项（5 条依赖本机语音模型的跳过）、浏览器 e2e 10 项。
- **`npm test` 和 `npm run test:browser` 不要同时跑**：都会起测试服务器抢端口，会出现假的 ECONNRESET 失败。
- 交付前：`npm run check` → `npm test` → `npm run test:browser`，全绿才算过。

## 14. 排错 FAQ

**启动报 `EADDRINUSE`**：改 `.env` 的 `PORT`，或先关掉占用 7788 的旧进程。

**控制台提示"需要登录控制台"**：访问 `127.0.0.1:7788`，密码是 `CONSOLE_PASSWORD`；改密码后旧会话失效。

**提示没有配置 Key**：`.env` 的 `DEEPSEEK_API_KEY` 没填或没生效；填完重启。

**QQ 一直不上线**：先看 SnowLuma/NapCat 自己的管理页是否在线；核对 `ONEBOT_TOKEN` 与 `BIZHI_QQ_PROVIDER`；确认登的是**小号**。程序不会替你反复重启 QQ。

**换模型后搜索变差**：正常现象——DeepSeek 搜索/读页接口只对官方地址有效，别家会自动退回免费抓取（只有摘要）。想保留搜索质量，接口地址留空继续用官方。

**小红书/抖音提示"要求验证"**：平台风控。按提示人工处理，程序会自动停 6 小时。

**费用台账和账单对不上**：本地台账是估算，不是账单；换模型后单价按旧表估算。

**想换角色/改名**：设置「角色与称呼」改名；人设改 `config/persona.md` 或 `BIZHI_PERSONA_FILE`。

## 17. 能力边界与风险

- **不是实时通话**：陪伴视图是摄像头 + 麦克风 + 语音合成 + 字幕，没有 WebRTC；"视线跟随"是鼠标视差。QQ 语音只能发语音消息，不能打断、不能撤回已提交的语音。
- **不是"赛博永生"**：记忆是"资料库 + 按需读取"，不会改变模型权重。
- **平台自动化天生脆弱**：网页结构一变就可能读不到；所有"未知结果"都会停下等人核对，不假装成功。
- **账号风险**：QQ / 小红书 / X / 抖音自动化违反平台规则可能导致限流或封号，请只用小号、低频、人工确认公开内容。
- **公开内容**：有自动隐私检查，但不是绝对保证，重要内容请自己过目。
- **费用**：本地台账是估算；余额未知时每日上限仍然生效。
