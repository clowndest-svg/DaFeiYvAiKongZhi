# BiZhi · 本地 AI 陪伴与账号控制台

使用 DeepSeek 的本地陪伴项目：网页/QQ 聊天、三层记忆、心情、日记和周记、主动消息、语音与图片表情，以及有明确开关和上限的小红书/QQ 空间互动。

## 功能与边界

- **聊天**：中文角色对话、图片输入、网页流式回复与停止；QQ 私聊、群 @ 与白名单群的选择性插话。
- **陪伴视图**：立绘跟随鼠标视差、按心情和表情标记换图、呼吸和眨眼、字幕、快捷回话、桌宠小窗。可打开摄像头让她看实时画面，可用麦克风说话（本机识别），可用服务端语音念回复。全部默认关闭，需要逐项打开；非本机或 HTTP 访问时设备功能会直接说明不可用。
- **内在状态**：可选的神经递质情绪底座（多巴胺/血清素/催产素/皮质醇/去甲肾上腺素，指数衰减 + 真实事件冲量）、可选的拟人遗忘曲线（记忆强度按半衰期衰减，被想起就变牢）、感官记忆（尝到/闻到/看到，必须有他的原话做证据）、以及从库里真实计数得到的大脑统计和人格锚。
- **记忆**：近期消息、重点记忆、长期周记；自动压缩与交接。日记、周记、交接信分别保存在 `data/daily`、`data/weekly`、`data/letters`。不全量注入历史日记。
- **主动**：空闲窗口内随机排程、不回复达到上限就停；QQ 私聊可补一句；深夜回复较慢且不发额外语音/表情。
- **语音**：Edge TTS（在线，可选十几个中文音色）→ 可选本地 Matcha / Piper → Windows SAPI；SenseVoice 本地识别。模型和运行环境需另外安装，不包含在 Git 仓库中。
- **本地离线音色（可选，默认不启用）**：`npm run tts:install-local` 把 matcha 中文权重下到 `voice/matcha/`（约 130MB，不在仓库内），音色下拉里选「本地离线 · Matcha」。推理跑在独立子进程里，不占显存；空闲 90 秒自动卸载；失败按原链回退。注意 data-baker 数据集**仅供非商业使用**，这套权重只适合本机自用，不许打进任何对外交付包。
- **同一句话 · 多音色对比试听**：控制台「QQ 聊天行为」里有按钮，把同一句文本同时喂给各个候选音色，你听着选，选中才写回设置。自然度不由代码断言，也不由我替你的耳朵决定。
- **QQ 语音对话模式（默认关）**：打开设置里的开关后，在 QQ 私聊发 `/语音聊天` 进入，发 `/挂断` 结束；她连续用语音回你，你发新语音时还没发出去的那条会被作废。
- **表情**：内置蓝鲸角色素材、原生 face、主人教的 mface/图片。开关、否定请求和冷却在发送时生效。
- **QQ 空间**：文字说说、读动态和评论、有限额的回复。Cookie 必须属于设置中的机器人号；主人号和其他号会被拒绝。
- **小红书**：专用 Chrome 登录、读取笔记、评论/回复、点赞/收藏、图文草稿和发布、数据小结。每个操作通过同一浏览器队列；验证/限制页出现后停止。
- **小红书私信**：主人自动回复必须先明确绑定稳定会话，且必须识别出一条新的入站消息。陌生人回复仍逐条确认。昵称不足以证明身份，无法识别方向/消息 ID 时不自动发。

**未实现且本轮不开发**：关注、视频笔记、自动改资料、空间图片说说、抖音/微信账号接管、一键导出。已有资料建议和抖音文案仅为草稿。通知页完整的评论/@、赞藏条目解析也未实现，只有角标读取。

**陪伴视图不是实时视频通话**：它是摄像头 + 麦克风 + 服务端语音 + 字幕 + 立绘的组合，没有 WebRTC 通话协议；立绘的“视线跟随”是鼠标视差和换图，不是 Live2D 骨骼跟踪，也没有唇形同步。项目仍是纯 Node + 浏览器，不打包桌面端。

**QQ 语音对话也不是实时通话**：OneBot v11 / NapCat 没有语音通话（VoIP/RTC）动作，只有 `record` 语音消息段，所以做不到这些，界面和文档也不许声称做得到：她不知道你什么时候开始播放、播放到哪，无法打断你正在听的那条；已经提交给 NapCat 的语音收不回来（新语音入站时会立刻作废「还没提交」的旧回答，这是协议能力极限）。控制台状态里会如实显示：本场已说几条、当日总量、上次发送时间；端到端延迟没实测过就显示「未测量」，不拿字数编时长。

## 安装与启动

需要 **Node.js 22.16+（推荐 24 LTS）**。Windows 适合本项目的 NapCat 和 SAPI 通道。

```bash
npm ci
```

复制 `.env.example` 为 `.env`，填写 DeepSeek API Key、独立随机 OneBot 令牌和控制台密码。设置页填写**你自己的机器人 QQ 小号**；默认账号为空，不会默认使用项目作者的账号。

```bash
npm start
```

打开 `http://127.0.0.1:7788/`，输入 `.env` 中 `CONSOLE_PASSWORD`（兼容 `CONSOLE_TOKEN`）。改密码后旧会话失效，退出立即吊销。

Windows 可双击 `run.bat`。隐藏运行使用 `start-bizhi-hidden.vbs`；同时启动 Node 与已安装 NapCat 使用 `start-all-hidden.vbs`。`install-autostart.vbs` 将**当前目录**注册为 Windows 登录后自启；不会自行执行注册或搬动 QQ 用户资料。

停止使用 `stop-all.bat`。进程管理只匹配本项目的入口/可执行文件，不按端口结束任意进程，也不全机结束所有 QQ。升级前已经用旧相对路径启动的 Node 可能需手动关闭一次。

## QQ / NapCat

1. 从 [NapCatQQ 官方发布页](https://github.com/NapNeko/NapCatQQ/releases) 安装匹配你 QQ 版本的 NapCat，程序放在本地 `napcat/`（不提交）。
2. 在 NapCat 配置 OneBot v11 反向 WebSocket：`ws://127.0.0.1:7788/onebot`，令牌与 `.env` 的 `ONEBOT_TOKEN` 一致。
3. 网页设置机器人小号并扫码；不要用主人号扫码。首次私聊需在设置页确认主人，或手动绑定。
4. 每个连接都核对自己的身份，未知身份或错号不能发送或获取凭据。接通 WebSocket不等于收发均正常：出站测试只证明发送，入站请从另一个设备发一条消息验证。

NapCat 使用个人 QQ 账号有平台规则和封号风险，只用专用小号，不群发，不高频互动。主号与机器人同机可能共享 QQ 数据；本项目**没有实现独立 QQ 数据目录**。请根据 QQ 客户端实际状态处理登录验证。

## 小红书

在设置页点击“打开登录窗口”，在专用 Chrome 完成扫码/验证码；不保存密码。配置目录为 `data/xhs-profile`。调试端口只供本机使用，不要向公网开放。升级后的归属检查可能拒绝旧浏览器实例，请手动关闭旧专用窗口后重新打开，避免误接管其他浏览器。

- 自动行为由设置的开关、活跃时段、每天/每小时限額控制。次数上限为 0 表示不做；额外总预算为 0 表示不设置该层上限，界面会说明。
- 主人私信：先读取当前账号资料和私信列表，选择你自己的会话，点击“确认这个会话是我”。换号后重新绑定。未知方向和缺少稳定消息 ID 不自动回复。
- 填稿返回确认稿件；发布前重新读取标题、正文、图片数并核对登录凭据。页面被改、账号改变或结果未知都会拒绝重发。
- “关闭浏览器”真正关闭本项目专用实例；“退出登录”等待退出后清登录态和账号缓存，保留用户素材。
- 遇到验证码、申诉或访问限制，不改指纹、不绕过验证，停止并在可见窗口人工处理。

网页结构会变化。自动化测试不能保证当前每一种平台页面都兼容；未识别响应保留最后成功缓存并报错，不冒充“没有消息”或“发送成功”。

动态配图只从内置素材或你明确放进 `data/public-media/` 的公开素材选择；`data/media` 的私密截图和语音不会回流为配图。

## 安全、费用与数据

- 服务监听 `127.0.0.1`。远程使用 **HTTPS 隧道**并设置强密码；不要公开 OneBot、NapCat WebUI 或 Chrome 调试端口。
- `Permissions-Policy` 只把摄像头和麦克风放给本控制台自己（`self`），定位仍然全关。
- 摄像头画面和录音只在陪伴页打开期间采集；切走或关掉就断流。录音在浏览器内重采样成 16k WAV 后交给**本机** SenseVoice 识别，临时文件用完即删并由清理任务兜底。
- 让她看、控制台念话有各自的每日上限和节流；念话不占用 QQ 语音额度，且合成失败不计次。网页识别不设日限（本机识别不花钱），但受单次时长、体积、同一时刻只跑一个和每分钟操作数上限约束。
- 私密截图和音频也受会话鉴权。登录/退出和副作用请求有跨站保护。
- 公开生成不读取主人私密档案、日记或情绪原因。公开出口统一检查身份/敏感称呼/凭据/私聊照搬；这不是对模型隐私判断的绝对保证，请审阅重要公开内容。
- 聊天和所选图片会发送给 **DeepSeek**；在线 Edge TTS 也会把待合成文字发送给微软服务。Piper 与 SenseVoice 离线运行。QQ/小红书/空间收到的是你授权发送的内容。
- 成本为本地台账估算，不是账单；流式中断有 usage 则记录，无 usage 的部分输出标为估算。实际价格、汇率和模型价格可能变化，不要把台账当精确账单。
- 余额未知时本地每日费用上限仍生效。额外自动动作会降级，普通回复保留。正在执行的请求可能让台账略超过阈值。
- SQLite 一致性备份保留 7 份；聊天和记忆不自动删除。过期临时媒体、计数键、事件和日志按保留策略清理。
- `.env`、运行设置、所有 `data/`、旧 `audit/`、账号资料、模型/安装包、venv 均不提交。私有历史审计材料只留本机。修改角色可直接改通用 `config/persona.md`，私有角色可用 `BIZHI_PERSONA_FILE` 指定文件。

## 测试与隔离演示

```bash
npm run check
```

```bash
npm test
```

普通测试使用独立 data/settings/persona、模拟模型和本地 HTTP/WS 夹具，禁止访问生产端口/外网或控制真实进程。本机语音模型相关用例单列：

```bash
npm run test:local
```

该命令要求本机已安装 Piper、SenseVoice 和 Edge TTS 环境；模型缺失时失败，不装作通过。示例资源位置：`asr/model/model.int8.onnx`、`asr/model/tokens.txt`、`asr/piper/piper.exe`、`asr/zh_CN-huayan-medium.onnx`、`voice/pyenv/Scripts/python.exe`（安装 edge-tts）。模型许可请依据对应上游模型卡。

真机浏览器端到端（需要本机安装 Chrome 或 Edge；陪伴用例会用假摄像头/假麦克风跑完整采集—识别—合成—播放链路）：

```bash
npm run test:browser
```

界面体检（起一个隔离演示实例并灌入示例数据，在 1440/1024/768/390/337 五档视口 × 五个视图上量横向溢出、真遮挡、文字截断、元素出界、可点区域过小和 WCAG AA 对比度；任何一项不达标就非 0 退出）：

```bash
npm run audit:ui
```

隔离演示（7790，模拟模型，密码 `demo-password`，不动真实账号）：

```bash
node tools/demo.mjs
```

在线 DeepSeek smoke 会花钱，需显式确认参数，使用隔离台账且不发送你的私聊：

```bash
npm run smoke -- --confirm-cost
```

详细优化与功能关联见 [完整方案](docs/OPTIMIZATION_PLAN.md)；本轮的实际测试结果与未执行的真机动作见 [验收报告](docs/VERIFICATION.md)。
