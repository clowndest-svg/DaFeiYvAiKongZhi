# 小知（BiZhi）· 本地 AI 陪伴与多平台账号控制台

一个跑在你自己电脑上的 AI 女友「小知」：网页和 QQ 都能聊天，有长期记忆、情绪和自己的生活；同时她还能替你打理 QQ 空间、小红书、X（推特）和抖音——每一样动作都有开关、限额和可查的记录。

> 本仓库是完整可运行的源码。所有数据（聊天、记忆、日志、浏览器登录态）只存在本机 `data/` 目录，不会上传到任何服务器；只有你主动配置的模型/平台会收到相应内容。

## 1. 它是什么

- **一个角色**：她叫小知（默认人设，可在设置里改名），说话方式、喜好和边界写在 `config/persona.md`（或 `BIZHI_PERSONA_FILE` 指定的文件）里，你可以直接改。
- **一个程序**：纯 Node.js，无编译步骤。跑起来后是一个网页控制台（默认 `http://127.0.0.1:7788/`），QQ 通过协议端（NapCat / SnowLuma）接进来。
- **一套记忆**：聊天内容→重点记忆→长期周记/交接信，层层沉淀；她自己还会反思、写日记、主动找你。
- **一个运营助手**：QQ 空间、小红书、X、抖音的登录、读内容、发草稿、评论回复，全部在控制台里操作，带真实回执和风控冷却。

技术栈：Node.js 22.16+（推荐 24 LTS）、原生 `node:sqlite`、原生 HTTP/WebSocket、无前端构建（`web/` 下是原生 HTML/CSS/JS）、DeepSeek API 作为语言模型、Playwright 用于测试。

## 3. 五分钟跑起来（新手从这里开始）

### 第 0 步：准备

- Windows 10/11（推荐；Linux/macOS 能跑 Node 部分，QQ 协议端和语音会有差异）
- 安装 [Node.js 24 LTS](https://nodejs.org/)（最低 22.16）。装完在命令行确认：

```bash
node -v
```

### 第 1 步：拿到代码

```bash
git clone https://github.com/clowndest-svg/DaFeiYvAiKongZhi.git
cd DaFeiYvAiKongZhi
```

### 第 2 步：安装依赖

```bash
npm ci
```

> 只有 `ws` 和可选的语音包，几分钟内装完。前端不需要构建。

### 第 3 步：写配置文件

把 `.env.example` 复制成 `.env`，最少填两项：

```ini
DEEPSEEK_API_KEY=sk-你的DeepSeek密钥        # 必填，模型调用用（platform.deepseek.com 申请）
CONSOLE_PASSWORD=换成一个你自己的登录密码    # 必填，打开控制台要输
```

其余变量可以先不管（见[配置详解](#5-配置详解env)）。

### 第 4 步：启动

```bash
npm start
```

看到类似输出就成功了：

```
小知已启动：http://127.0.0.1:7788
模型：deepseek-flash | 模拟模式：关
QQ 通道：ws://127.0.0.1:7788/onebot/...
```

### 第 5 步：打开控制台

浏览器访问 `http://127.0.0.1:7788/`，输入 `CONSOLE_PASSWORD`，就能和她聊天了。**不需要 QQ、不需要任何社交平台**，网页聊天是开箱即用的。

想接 QQ、小红书这些？继续看第 6、7 节，都是"在设置页点按钮/扫码"的量级。

### Windows 一键方式（可选）

- 双击 `run.bat` 启动
- `start-bizhi-hidden.vbs`：无窗口后台运行
- `start-all-hidden.vbs`：同时启动 Node 和已安装的协议端
- `install-autostart.vbs`：把**当前目录**注册为登录自启
- `stop-all.bat`：停止本项目进程（只按本项目的入口/可执行文件匹配，不会乱杀别的程序）

## 4. 第一次打开会看到什么

左侧是导航栏，六个页面：

- **聊天**：和她对话。有"停止"按钮，可以发图片。
- **陪伴**：立绘 + 摄像头/麦克风/语音（默认关闭，需要逐项打开）。
- **记忆**：她记住的重点、日记、信；可以手动加记忆、更正记忆。
- **动态**：内容创作（让她写一条 / AI 资讯选题 / 评论区替她说话）→ 平台互动（空间 / 小红书私信 / 小红书图文）→ 生产与记录（视频任务 / 动态记录 / 待处理 / 今日费用）。
- **日志**：她写给自己的话、最近 30 条内心独白、运行事件、服务日志尾巴。
- **设置**：按功能分 10 个区。**平台的登录和开关都在设置里按平台分区**（小红书 / X / 抖音 / QQ），不用去别处找。

建议的第一小时路线：先聊几句 → 设置里改名字/人设 → 开「主动陪伴」→ 有 QQ 小号的话接 QQ → 最后再接社交平台。

## 5. 配置详解（.env）

| 变量 | 必填 | 说明 |
|---|---|---|
| `DEEPSEEK_API_KEY` | ✅ | 模型密钥。不填也能启动，但聊天会提示未配置 |
| `DEEPSEEK_BASE_URL` | | 默认 `https://api.deepseek.com`，换兼容服务时改这里 |
| `DEEPSEEK_MODEL` | | 默认 `deepseek-flash`；更贵的更强模型可在设置里切 |
| `PORT` | | 默认 `7788` |
| `CONSOLE_PASSWORD` | ✅ | 控制台密码。外网访问必须设，且要配 HTTPS 隧道 |
| `CONSOLE_TOKEN` | | 旧版兼容；设置密码后不再需要 |
| `ONEBOT_TOKEN` | 接 QQ 时 | 和协议端约定的随机字符串，两边必须一致 |
| `BIZHI_QQ_PROVIDER` | | `napcat`（默认）或 `snowluma`；切换前先看 `docs/qq-provider-migration.md` |
| `X_PROXY_URL` | 用 X 时 | 本机代理地址（默认 `http://127.0.0.1:7897`）。X 在国内直连不通 |
| `BIZHI_DOUYIN_REPLY_ENABLED` | 抖音真发时 | `1` 才允许真实发送评论；默认关闭，只起草不发出 |
| `QZONE_BRIDGE_URL` / `QZONE_BRIDGE_TOKEN` | 可选 | 用外部桥发空间说说时用，一般不用 |
| `CHROME_PATH` | | 指定 Chrome/Edge 路径（自动探测失败时用） |
| `BIZHI_DATA_DIR` | | 数据目录，默认项目下 `data/`；想放别的盘就指这里 |
| `BIZHI_PERSONA_FILE` | | 私有角色文件路径（不想改仓库里的 `config/persona.md` 时用） |
| `OPEN_BROWSER` | | `1` 启动时自动打开控制台；默认不开 |
| `BIZHI_PRICING_JSON` | 可选 | 自定义费率，用于本地费用台账估算（不是平台账单） |

密钥安全：`.env` 已被 git 忽略，**不要提交**；控制台日志里密钥会自动打码。

## 6. 接入 QQ（NapCat 或 SnowLuma）

QQ 是可选通道。不接也能用网页聊天。

### 方案 A：NapCat（默认）

1. 从 [NapCatQQ 发布页](https://github.com/NapNeko/NapCatQQ/releases) 下载与你的 QQ 版本匹配的包，解压到项目下的 `napcat/`（该目录不提交）。
2. 在 NapCat 配置 OneBot v11 反向 WebSocket：地址 `ws://127.0.0.1:7788/onebot`，令牌与 `.env` 的 `ONEBOT_TOKEN` 一致。
3. 控制台 → 设置 →「QQ 连接与行为」→ 填**你自己的 QQ 小号**并扫码登录（不要用大号）。
4. 首次私聊后按提示确认"主人"身份。

### 方案 B：SnowLuma

完成了 `docs/qq-provider-migration.md` 里的实机验收后，可设 `BIZHI_QQ_PROVIDER=snowluma` 并冷启动。不能只改地址就当迁移成功。

### 掉线会发生什么

- 协议端自己会每 3 秒重连一次；**程序不会自动杀 QQ 进程**（杀进程会把登录踢掉，反而要重新扫码）。
- 只有当"开机后长时间没连上、且确认 QQ 进程和启动器都不在"时，才会尝试拉起一次。
- 控制台分别显示：通道连没连上、账号在不在线（探不到就写"未确认"）、最近 7 天断线次数与恢复时长。

> 风险提示：用个人 QQ 号跑协议端有平台规则和封号风险。只用专用小号，不群发、不高频互动。

## 7. 接入小红书 / X / 抖音 / QQ 空间

所有平台都是**专用浏览器 + 扫码登录**，不保存密码；登录态存在本机 `data/` 下。入口统一在**设置页对应分区**。

### 小红书（设置 → 小红书）

- 「打开登录窗口」→ 在专用 Chrome 里扫码；「验证登录」确认状态。
- 开关控制：自动浏览并评论、自动回自己笔记下的评论、点赞、收藏、自动发布、私信。
- 私信自动回复前，需要先在你的私信列表里点「确认这个会话是我」建立绑定。
- 额度：每天/每小时/总动作都有上限，0 表示不做。遇到验证页会停 6 小时并写事件。

### X / 推特（设置 → X / 推特）

- X 在国内直连不通，必须走本机代理（`.env` 的 `X_PROXY_URL`）。代理没起来她不会硬闯。
- 登录窗口不带自动化标记（Google 看这个）；登完点「验证登录」，不用关窗口。
- 「让她起草一条」只填进编辑器；「发布填好的那条」才会真发，且只发逐字核对过、15 分钟内填的那条。

### 抖音（设置 → 抖音）

- 「显示登录页面」→ 扫码；「读取我的作品」完成账号绑定。
- **评论与回复**：粘贴视频链接 → 读取当前评论 → 生成回复 → 填进后台草稿 → 你点「确认发送」。发送前会核对视频、楼层、对象、内容和按钮五处；发完用"新评论 ID + 目标楼层 + 本账号"三重回执确认，确认不了就标"结果未知"，绝不盲目重发。
- **真实发送闸门默认关闭**：需要在 `.env` 设 `BIZHI_DOUYIN_REPLY_ENABLED=1`（建议先在评论区亲手验收一条）。
- **自动行为开关**：定时检查评论 / 自动回复 / 自动刷视频。刷视频会打开视频页采两帧画面 + 标题简介交给视觉模型，生成理解笔记（声音不接入），每半小时一条、每天最多 6 条，走社交预算。
- 遇到验证页会停 6 小时。

### QQ 空间

- 设置 →「动态与空间」里配置后，动态页「空间互动」可以读说说和评论、有限额地回复、发文字说说。
- Cookie 必须属于设置里的机器人号，否则拒绝。

## 8. 她的人格、记忆与「自己写的话」

- **人设**：`config/persona.md`。改完立即生效，不用重启。
- **三层记忆**：近期对话（自动压缩）→ 重点记忆（事后反思抽取，必须带你的原话作证据）→ 长期周记/交接信。日记在 `data/daily`、周记在 `data/weekly`、交接信在 `data/letters`。
- **自我档案**：她可以在事后反思时**追加或整段重写「她自己写的话」**（注入提示词时优先级高于普通说话参考）。你可以在「日志」页看到她写了什么，也能一键清空让她重来。
- **说话方式的边界**：大部分表达（怎么开场、用不用表情、语气）由她自己决定；只有三条底线不能改——只用有记录的事实（不许编造搜索结果）、私密信息留在私聊、你说停就停。
- **手动修正**：记忆页可以加记忆、更正记忆；公开内容（说说/笔记/评论）发出前都过隐私检查。

## 9. 日志、数据与隐私

### 东西都在哪

| 内容 | 位置 |
|---|---|
| 数据库（聊天、记忆、事件、费用） | `data/bizhi.db`（SQLite，自动备份保留 7 份） |
| 应用日志（每天一份，保留 14 天，自动脱敏） | `data/logs/app-YYYY-MM-DD.log` |
| 进程输出 | `data/logs/server.out` |
| 她的内心独白 | 挂在每条回复的 meta 里，看「日志」页最方便 |
| 日记 / 周记 / 交接信 | `data/daily` / `data/weekly` / `data/letters` |
| 小红书 / X / 抖音登录态 | `data/xhs-profile` / `data/x-profile` / `data/douyin-profile` |
| 公开配图素材 | `data/public-media/`（只有这里和内置素材会被选为配图） |

### 怎么看

- 控制台「日志」页：她写给自己的话 → 最近 30 条内心独白（含当时的回复）→ 运行事件 → 服务日志尾巴（可切应用日志/进程输出）。
- 想直接翻文件也行，路径见上表。

### 隐私

- 服务只监听 `127.0.0.1`。要在外网用，请走 **HTTPS 隧道**并设置强密码；不要把 OneBot、协议端 WebUI、Chrome 调试端口暴露到公网。
- 摄像头/麦克风只在陪伴页打开时采集，切走即断；录音在本机识别。
- 聊天和图片会发给 DeepSeek；在线语音合成会发给微软。除此之外的数据不出本机。
- `.env`、`data/`、账号资料、模型与安装包都不进 Git。

## 11. 测试与验收

- 测试全部跑在隔离目录（独立 data/settings/persona，模拟模型，本地 HTTP/WS 夹具），**不会碰真实数据或真实进程**。
- 当前规模：单元/契约 625 项（620 过、5 条依赖本机语音模型的跳过）、浏览器 e2e 10 项。
- **`npm test` 和 `npm run test:browser` 不要同时跑**：两套都会起测试服务器抢端口，会出假的 ECONNRESET 失败。
- 交付前至少跑：`npm run check` → `npm test` → `npm run test:browser`，全绿才算过。

## 12. 排错 FAQ

**Q：启动报 `EADDRINUSE`（端口被占）**
改 `.env` 的 `PORT`，或先停掉占用 7788 的旧进程。

**Q：控制台打不开 / 提示"需要登录控制台"**
确认访问的是 `127.0.0.1:7788`；密码是 `.env` 里的 `CONSOLE_PASSWORD`（改完要重新登录，旧会话会失效）。

**Q：聊天提示"还没有配置 DeepSeek API Key"**
`.env` 里 `DEEPSEEK_API_KEY` 没填或没生效；重启程序。

**Q：QQ 一直不上线**
先看协议端自己的控制台是否在线；再看 `.env` 的 `ONEBOT_TOKEN` 和协议端配置是否一致；确认机器人号是**小号**。程序不会替你反复重启 QQ。

**Q：X 打不开/超时**
X 必须走本机代理。确认 `X_PROXY_URL` 指向的代理正在运行。

**Q：小红书/抖音提示"要求验证"**
平台的正常风控。按提示在专用窗口里人工处理，程序会自动停 6 小时，不会硬闯。

**Q：她搜资料说"没搜到"**
搜索有每日额度、隐私闸门（含数字/群聊内容不发外网）；余额或额度用尽也会如实说没查到。这是设计行为，不会编结果。

**Q：费用台账和 DeepSeek 账单对不上**
本地台账是估算（按记录的 token × 配置费率），不是账单；流式中断等场景会标"估算"。

**Q：想换角色/改名**
设置 →「角色与称呼」改名；人设文本改 `config/persona.md`（或 `BIZHI_PERSONA_FILE` 指向的文件）。

## 15. 能力边界与风险

- **不是实时通话**：陪伴视图是摄像头 + 麦克风 + 语音合成 + 字幕的组合，没有 WebRTC；"视线跟随"是鼠标视差，不是 Live2D 骨骼。QQ 语音也只有语音消息段，没法打断、不能撤回已提交的语音。
- **不是真"赛博永生"**：记忆是"资料库 + 按需读取"，模型权重不会因对话而改变；想做到权重层面的记忆只能本地部署专门方案，本项目没有声称做到。
- **平台自动化天生脆弱**：网页结构一变就可能读不到。所有"未知结果"都会停下等人核对，不会假装成功；这不代表永远能自动成功。
- **账号风险**：QQ/小红书/X/抖音自动化违反平台规则可能导致限流或封号，请只用小号、低频、人工确认公开内容。
- **公开内容**：自动检查敏感信息，但不是绝对保证，重要内容请自己过目。
- **费用**：本地台账是估算；余额未知时每日上限仍然生效，自动动作会降级，正常回复保留。
