# 项目存储与隐藏运行

## 本机路径

本项目位于 `D:\RuanJian\BiZhi`，Node 位于 E 盘。数据库、聊天、媒体、日志、模型与账号资料继续使用原来的 D 盘项目目录。

临时文件和工具缓存由 `src/storage.js` 统一配置，只设置当前进程及其子进程的环境，不修改 Windows 用户全局 TEMP、APPDATA、LOCALAPPDATA 或其他项目设置。

| 内容 | 项目目录下的位置 |
| --- | --- |
| 按进程隔离的临时文件 | data/runtime/tmp/worker-PID-随机值 |
| 启动器引导临时目录 | data/runtime/bootstrap-tmp |
| npm、pip、uv 下载缓存 | data/runtime/cache/npm、pip、uv |
| Playwright 下载的浏览器 | data/runtime/cache/playwright |
| Hugging Face、Torch 等缓存 | data/runtime/cache/huggingface、torch、xdg、matplotlib、numba |
| 项目专用 Python 基础运行时 | data/runtime/python |
| 备份 SSH 主机校验记录 | data/sentinel/known_hosts |

正常启动、后台守护、安装工具、npm 脚本及隔离测试均接入该配置；原生 Python/语音工具继承 TEMP/TMP。已在本机复制并逐文件校验 Python 3.10.20 的 4175 个文件，更新项目变声环境的 pyvenv.cfg；真实 Python/Torch 检查确认基础运行时、临时目录和 Torch 缓存均指向 D 盘。旧配置备份保存在被 Git 忽略的 data/migration-backups/storage/。

SSH 首次准备项目主机校验文件时保留已有用户 known_hosts 中的主机密钥记录，后续新增记录写项目目录，系统级信任配置继续保留。未关闭主机密钥校验，也未把私钥写入仓库。

本机专用备份密钥的过宽文件权限已收紧到当前用户；真实服务器报平安请求成功。界面报平安/备份按钮的重复 JSON 编码已修正，并在浏览器中分别核对发送的动作，避免点备份却只执行报平安。

## 清理规则

隐藏守护启动及其后每六小时执行一次保守清理，结果保存在 data/runtime/cleanup-state.json。

- 只处理本项目带有效归属标记的临时工作区；所属进程仍存活、发现子进程、标记无法核实、含符号链接/目录联接或扫描不完整时保留。
- 已退出进程的工作区超过 24 小时可清理；符合清理条件的临时文件超过 1GB 时，优先清理一小时以上的旧工作区。活动文件不为达到容量目标而强删。
- npm/pip/uv 可重建下载缓存超过 30 天可清理；超过 512MB 时，优先清理七天以上的旧文件。发现活动工具或归属不明时暂缓。
- 安装好的浏览器、Python、模型、数据库、聊天、登录资料与备份不属于自动删除范围。
- 清理有扫描上限，异常不会重启或阻塞业务主程序。

## 后台与验收

后台入口使用隐藏 WScript，子工具设置 windowsHide，PowerShell 探测同时使用 Hidden 参数。隐藏启动器出错时返回退出码，避免弹出脚本错误窗口。需要本人登录的浏览器界面仍由用户主动打开。

后台守护记录启动宿主，宿主确认退出后自行结束并释放单实例锁，避免停止计划任务后留下孤立守护、阻挡后续正常启动。本机已完成旧孤立守护交接，由新隐藏启动器正常启动，宿主进程与唯一守护均已核对。

本地测试 570 项，565 通过、5 跳过；其中覆盖缓存环境继承、活动进程保护、过期及容量清理、链接越界保护和缓存清理延后。语法检查与三组浏览器回归通过。

已在维护中备份并切换后台环境。原主程序与协议端随旧守护退出后，新守护各一次成功恢复；QQ 账号校验通过，原发送记录未重发，费用全部结算，数据库完整性正常，维护已解除。

## C 盘边界

本项目新建的可控临时文件与工具缓存已指向 D 盘。Windows 自身记录、现有 Chrome/QQ 程序及其共享用户目录不由本项目迁移，不承诺整台电脑 C 盘零写入。

C 盘已有约 701MB 的 Playwright 共享安装缓存保持原样，本项目后续不再使用该目录下载浏览器。两个早期测试目录合计约 0.32MB：自动审批拒绝了清除操作，仅返回 blocked by policy，因此保留，未通过其他方式删除。它们未被当前项目代码引用。
