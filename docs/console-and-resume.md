# 控制台入口与睡眠恢复

鲸鲸页顶新增 SnowLuma 入口，QQ 设置内另有“控制台”和“QQ 进程接入”入口。均在新标签页打开，并使用 `noopener noreferrer` 隔离窗口。地址读取本机运行时配置，默认 `http://127.0.0.1:5099/`。鲸鲸负责聊天、记忆和任务，SnowLuma 负责 QQ 接入；两者继续使用各自登录认证，不在链接中传密码或令牌。远程浏览器隐藏本机跳转并解释如何访问，避免误连手机自己的 localhost；不开放管理端口。

## Windows 生命周期

- 重启电脑后，**登录当前 Windows 用户桌面后**隐藏启动。未登录前不启动需要桌面会话的 QQ 组件。
- 同一计划任务另有解锁延迟 10 秒、系统恢复事件延迟 15 秒及每 5 分钟检查触发器；多实例策略 IgnoreNew，守护还有进程互斥锁。
- 不设置运行时长限制，不因切换电池或结束空闲停止任务，不主动唤醒电脑，不修改全局电源计划。
- 睡眠期间电脑不处理聊天。守护发现超过 90 秒的调度间隔后，先保留 30 秒恢复缓冲；缓冲内不拉起缺失进程、不做磁盘清理。已有进程继续运行；只有确认进程不存在才按现有限次退避策略恢复，活着但异常或身份未知的进程只标记待检查。
- Windows 强制结束进程、注销、断电、QQ 掉线不能保证登录态保留。后台运行时恢复不等于 QQ 已接通，仍校验机器人账号。必要时手动登录小号、在 SnowLuma 核对身份后加载，自动注入保持关闭。
- 手动停止标记优先于所有触发器。`-UpdateOnly` 更新任务定义时保留停止状态，不擅自重新启用。设置的“后台启动与恢复”卡显示任务配置和守护最近检查状态。

任务为当前用户普通权限的交互任务，入口是隐藏 WScript，无 PowerShell 桌面窗口。运行数据继续使用 D 盘原目录和数据库；恢复不重放未知发送结果。

## 验证范围

完成 572 项单元测试（567 通过、5 项条件跳过）、195 个 JavaScript 文件语法检查；浏览器覆盖新标签页跳转、空 opener、设置关联及 320–1440 像素布局。先前两个浏览器用例通过，修正测试页面 UTF-8 后设置用例独立通过。

本机任务注册成功，已核对导出的四种触发器、无限期五分钟重复、普通交互权限、电池和空闲策略。上线前维护排空并在线备份数据库及设置。真实整机重启、睡眠/唤醒未主动执行，以免打断用户桌面工作；时间间隔恢复由故障模拟测试覆盖。以上不代表整机断电或长稳验收。
