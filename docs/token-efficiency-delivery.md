# Token 与后台整理优化

## 请求与任务

反思、压缩和交接使用显式非思考模式。反思输出配置实际参与请求，取值范围为 800–1600 tokens。后台截断、空正文和不合法 JSON 进入待检查状态，网络瞬时错误最多尝试两次。普通聊天支持自动、开启、关闭三种思考模式，自动模式通过本机关键词识别技术、推导和调试问题。

内心整理采用 SQLite 持久工作队列。每条已完成的主人聊天回复绑定来源消息 ID，默认四回合成批，最小间隔 120 秒。批次不足时按到期时间处理。来源读取完整原始消息，大输入会减小批次数量。重启后恢复待处理任务，并补回回复已保存、入队前进程退出的消息。

模型结果的记忆、情绪等数据库写入与任务完成标记共享事务。失败任务可在聊天与记忆设置中重新排队。队列识别 QQ 投递状态，已确认的主人回复才进入整理。每日整理预算默认估算 0.5 元，费用预留和待对账金额共同参与拦截，待处理来源在预算恢复后继续执行。

## 上下文

静态规则、人设和相关固定背景置于稳定前缀，时间、情绪和召回信息位于其后。合并重复的说话说明，保留续聊、引用、边界、隐私、联网结果和消息分段约束。核心档案、惦记事项、感官线索和最近平台活动参与必要信息保留。

本机应用的初始参数为最近 16 条消息、最多 6 条召回记忆、召回预算 1200、系统提示预算 3500、单轮输入预算 6000。系统预算为本地估算，当前问题和必要规则具有保留优先级，长单条输入可能超过软预算。旧日记、周记和更多平台活动按查询相关性展开。

## 费用记录

新增任务 ID、请求序号、推理 token、输出状态、用量估算标记及费率版本。HTTP 失败和未知结果也进入请求追踪，同一任务重启后的序号继续递增。输入、输出、推理、缓存命中、重试、输出异常和待对账按功能显示。旧记录以历史汇总标记展示。

已知 DeepSeek 模型使用官方峰谷费率，2026 年日历按国务院放假安排判断，计费时段与入账日采用请求开始时刻及 UTC+8。美元换算继续显示估算属性，未来年份日历带估算标记。自定义费率表优先参与计算。

参考 [DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)、[上下文缓存](https://api-docs.deepseek.com/guides/kv_cache/)、[官方价格](https://api-docs.deepseek.com/quick_start/pricing/)、[国务院 2026 年节假日安排](https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm)。

## 验证

隔离数据库副本构建四种场景，输入 token 本地估算下降约 18%–24%。真实模型使用三组人工构造的整理样本进行旧策略与新策略对比。优化组三组均通过 JSON、原话依据和否定语义检查，推理用量均为 0。该样本估算费用下降 61.1%，旧策略其中一组出现无效 JSON。此项数据描述后台整理小样本，长期整体节省率需要后续实际运行记录确认。

单元回归覆盖截断停止、网络重试计数、峰谷边界、节假日、预算预留、重复入队、长来源、入队前崩溃及事务提交前故障。浏览器回归覆盖新增参数的分区保存与已有聊天、记忆、动态、陪伴功能。重型浏览器用例串行运行以控制本机测试资源占用。

最终本机结果为 594 项单元测试中 589 项通过、5 项条件跳过，四项浏览器用例通过，201 个文件语法检查通过，全页面六种宽度共 30 组检查通过。线上接口已核对优化参数、费用分类、队列状态及 QQ 身份和连接。

## 上线与恢复

维护排空后完成 SQLite 在线备份和配置备份，通过隐藏守护恢复主程序。备份位于本机忽略目录 `data/migration-backups/token-*`。上线核对机器人身份、QQ 连接、维护状态、队列和费用接口。

数据库迁移采用新增字段与表。回退时在维护排空后恢复旧程序及备份设置，继续使用当前数据库，保留上线后的原始对话、记忆和费用记录。随后重新核对账号身份、发送未知记录和预算。
