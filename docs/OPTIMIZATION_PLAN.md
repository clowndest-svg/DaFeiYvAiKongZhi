## 功能关联与修改原则

| 入口 | 当前调用链 | 本轮必须共同验证的边界 |
|---|---|---|
| 网页聊天 | `web/app.js` → `index.js` → `Companion` → prompt/memory → DeepSeek → SSE/落库 → reflect/compact/handover | 停止、断流、并发、费用、记忆和 UI 同步 |
| QQ 私聊/群聊 | OneBot → 身份与主人识别 → 防抖 → 图片/ASR → 同一聊天核心 → 文字/语音/表情/补话 | 不串号、不泄露、开关生效、投递结果真实 |
| 主动与日记 | Scheduler → 时间/次数/预算 → 模型 → 投递或文件/数据库 | 0 值、跨天、过期、失败退避、发送前复查 |
| 小红书 | Scheduler/网页/QQ 口令 → 浏览器队列 → 读取/生成/发布 → 配额/活动日志 | 同一页面不能被抢走；对人、对稿、对次数 |
| QQ 空间 | Cookie 导入/续期 → 读 feed/生成 → 隐私/身份检查 → 发布/回复 | 错 Cookie 拒绝、重复发送防护、不能把未知当成功 |
| 运维 | Windows 启动/停止脚本 → Node/NapCat/Chrome → 本地目录 | 只控制本项目进程、可搬目录、不影响主 QQ |

复用现有 `assertPublicContent`、`checkBotIdentity`、`withXhsBrowser`、`sendVoiceAndCount`、`tickStep`、SQLite 查询和原子 JSON 写入。只抽出真正需要共用/可测试的安全、时间、队列、进程控制小模块；不进行大规模框架迁移或纯命名重构。

8. **消除 SAPI 命令注入。** 当前 `JSON.stringify(text)` 被插入 PowerShell 双引号，`$()`/反引号等仍会被执行。改成固定脚本和安全数据传递，不把模型/用户文字当 PowerShell 代码。音频文件名用唯一 ID，修并发同毫秒覆盖；补音频 MIME、超时和失败文件清理。

11. **下载安全与资源上限。** 公网图片逐跳校验 DNS 解析结果并固定连接地址，拒绝私网、回环、链路本地、保留及 IPv4-mapped IPv6；使用整体截止时间与流式大小上限，不先无限 `arrayBuffer()`。错误/重定向及时关闭响应；媒体/素材路径校验真实目录与符号链接，统一图片魔数验证。

### C. QQ 与 QQ 空间身份、授权和幂等

**关键文件：** `src/channels/onebot.js`、`src/channels/qzone.js`、`src/social.js`、`src/index.js`、`src/db.js`。

12. **动作意图不反着执行。** 已复现“不要发说说”和无上下文“发个看看”会触发发布。要求明确的肯定发布意图；否定、询问、引用、假设不发；模糊承接只能在可核实的最近空间话题上下文中使用，否则正常聊天。
13. **OneBot 身份绑定到连接。** 不用全局/旧数据库 selfId 为未知新连接授权；区分每个 WS 的身份，出站选择正确且存活的机器人连接，补 `get_credentials` 等身份闸门。每次发送检查通道、当前主人/机器人配置；解绑/换号/停用取消旧任务，不在开关关闭后补发。
14. **空间 Cookie 身份一致。** 保存、NapCat 导入、自动续期以及发送前校验 Cookie 账号必须是配置机器人、不能是主人；错误输入不覆盖有效 Cookie。账号变化时清对应 feed/去重/健康缓存；Cookie 文件原子写入，续期不得悄悄换身份。
15. **发布/评论状态机与重复保护。** `posted` 不能退回 `approved`；同一动态只允许一个发送流程，重试/并发不能重复发布。统一处理人工确认、调度和 QQ 口令；人工“标记已发”与平台验证已发区分。评论按账号+目标评论 ID 去重，手动和自动共用。平台明确失败与“请求发出但结果未知”分开，未知结果不自动重发。
16. **空间健康不是 HTTP 200。** 只在解析到合法成功结构/明确空列表时记成功；未知 HTML、登录页和未识别响应不得清空已有 feed 或标 Cookie 健康。成功/失败标志互斥，短空列表和长错误页都测试；生成/发送失败不谎称已经发出。

**验收：** 双 WS 错号场景、旧身份重连、错 Cookie、停止后延迟任务、否定指令、并发重复发布及未知发送结果均有行为测试；假平台收到的动作数量和收件人准确。

### D. 时间、次数与预算调度

**关键文件：** `src/scheduler.js`、`src/budget.js`、`src/intentions.js`、`src/util.js`、设置契约与调度测试。

17. **修复自动发布永远排到明天。** 当前只在活跃时段进入 `maybeXhsPublish`，却用“下一次开始时刻”生成当天目标，实际永远落在次日。改成在当天剩余合法窗口选择时间，明确跨午夜窗口、错过窗口、当日次数/间隔和失败退避；目标与尝试标记可观测、可清理。
18. **0 值和设置即时生效。** 已复现 `proactive.maxPerDay=0` 仍生成。修所有次数型 `|| 默认值`；每日次数 0 不执行。费用上限/额外总闸的 0 保持既有“不设该上限”语义并标明。时间/频率设置修改后重排，不继续旧计划；生成后发送前重查开关、时段、额度及新入站消息。
19. **预算不依赖余额查询成功。** 本地今日花费到顶，即使余额未知也阻止额外自动动作；余额查询失败有退避和状态时间，不每 30 秒重打。跨天清理日预算限制、保留真实低余额状态；反思和语音等入口统一受其对应预算约束，仍保留必要的普通回复。
20. **惦记和梦按时间而非词面过期。** 不因跨天含“明早”就删除真正明早到期的事项；按明确 dueAt/过期时间、提及次数处理无效日期和完成项，优先最近到期而不是最远任务。梦里的日记必须标明实际日期；过期梦开头不能隔多天继续冒出来。
21. **维护失败可恢复。** 日/周任务、清理和子任务完成标记只在对应成功后设置；失败退避、事件节流，某一步失败不阻断其他步骤。排程和状态读数不调用真实外部动作。

**验收：** 固定时钟覆盖午夜、上海时区/UTC 宿主、相等窗口、当天启动、0 上限、预算未知/超支/次日恢复、生成过程中关闭开关/新消息到达。

### E. 聊天、流式、记忆与自然交互

**关键文件：** `src/llm.js`、`src/chat.js`、`src/memory.js`、`src/reflect.js`、`src/prompt.js`、`src/db.js`、`src/channels/onebot.js`。

22. **端到端取消与真实流式终态。** 网页停止/断线立即中止上游，包括首 token 尚未到达；清理 reader/监听器。SSE 处理跨块 UTF-8、尾帧、合法结束、错误和半截流；缺结束不能当完整成功。部分内容保留但明确标记，不进入自动反思/长期事实。
23. **费用与重试如实记录。** 拒绝/4xx 不盲重试，可重试错误遵守总超时和取消；失败重试已经得到的 usage 不丢。断流有 usage 就记实测，无 usage 的部分输出记“估算”，不宣称零成本/实测值。所有功能使用用户选定模型，不偷偷回落默认模型。
24. **私聊与网页共享会话串行。** 回复、反思、压缩/交接按正确会话快照运行；不把后来的消息算进前一次反思，不在生成中归档该会话。压缩与交接共用互斥和事务，超阈值不能被别的会话的“五天冷却”挡住。
25. **记忆确实保住最近与历史。** 压缩兼顾实际 prompt 压力和已积累的未压缩消息，避免只带滑窗而旧话永远未整理；日记/周记按预算选取近期内容，不能再拼完后截掉最晚部分。按会话取摘要；原话以真实消息 ID 排除已在上下文中的条目，而非机械跳过十条。自动核心事实必须能对应单条真实用户原文，拒绝空标点证据/跨条拼接，保存来源。
26. **流式和普通聊天行为一致。** 共用名字清理、心情参数和标记解析；更新过时的“语音和同内容文字一起发”等 prompt 文案，去除公开主题与隐私禁词的自相矛盾。不靠增加一大段死规矩制造“有人味”。
27. **表情与补话听从当前控制。** 模型 hint、小黄脸、mface、学习图片、兜底图片统一检查开关、否定、场景和同会话冷却；所有成功表情路径都记冷却，最近使用去重。群/访客不混入主人学习库。补话在最后一刻和分段间复查新消息/关停/改绑，只有确认投递后才标成功与计数。
28. **长消息和语音不制造假完成。** 修超过 12 段时把长尾塞进最后一条（已复现末条 8,020 字）；按句/字符安全分段，长输出受控分批且可打断，保留完整原文和投递状态。语音失败补文字但不把未知投递当明确失败重复发送；入站转码候选去重、整体截止时间、ASR 并发有界。

**验收：** 受控假 LLM/WS 覆盖停止前后、无首 token、半截、多路同时聊天、交接中聊天、无凭据 mock、名字更改、语音替代、关表情但模型要求发、负向请求、补话即将发出时新消息到达。
