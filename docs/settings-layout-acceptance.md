# 设置页布局与保存关联验收

## 调整

- 九个设置分区按需显示，切换只移动/隐藏原控件，保留输入草稿。桌面使用侧边分区导航，窄屏完整展示三列导航；支持方向键、Home/End 和焦点移动。
- 卡片连续单列排列，桌面表单字段双列、手机单列；避免不同卡片共用行高产生大块空白。按钮按可用宽度对齐，语音与变声高级参数默认收起。
- RVC 音色库进入原生模态弹窗，每页六项，支持名称/类别搜索、可用/当前音色筛选和翻页。多音色对比及最近事件也移入弹窗。关闭弹窗停止播放，迟到的试听结果不会在关闭后突然播放。
- 全部设置与分区保存入口统一保留；人设仍单独保存，RVC 选择/参数仍立即保存，页面明确说明各自生效方式。

## 保存关联

| 分区 | 保存范围 |
| --- | --- |
| 角色与称呼 | companion；人设使用独立按钮 |
| 聊天与记忆 | model、memory、search，以及记忆卡中的 dreamEnabled/dreamHour |
| 主动陪伴 | proactive 中除上述做梦字段外的设置 |
| 语音与感官 | tts、presence；RVC 独立保存后同步设置快照和版本 |
| QQ 连接与行为 | qq |
| 动态与空间 | social 的公共排期、草稿与空间字段 |
| 小红书 | social 中 xhs 前缀字段 |
| X / 推特 | social 中 x 前缀且非 xhs 的字段 |
| 界面与系统 | ui、cost；备份及维护动作仍使用独立接口 |

补齐聊天分区的联网及做梦字段，隔离不同社交平台分区的草稿；修复试听选择未标记草稿、RVC 保存后版本不同步，以及主表单可能覆盖已生效 RVC 配置的问题。RVC 接口支持 If-Match，过期修改返回 409；主表单与即时保存互斥，失败时保留其他草稿。选择 RVC 音色会明确启用，缺引擎/文件时不能选择。

## 本地验证

- 完整测试：566 项，561 通过、5 跳过、0 失败。
- JavaScript 语法检查：190/190 通过。
- 原有浏览器回归：登录、聊天、设置保存及冲突、维护、陪伴音视频场景通过。
- 新浏览器验收：九分区在 1440、1024、768、390、320 宽度下无横向溢出；连续卡片间距 12–20px。音色搜索、分页、选择、关闭后迟到结果、草稿保留、跨平台限额隔离、快捷朗读及后续保存均通过。
- RVC 接口使用隔离配置验证版本变化、旧版本拒绝及后续保存不覆盖参数；浏览器目录使用 36 个测试模型，不启动真实变声推理或触发外部平台发布。
- 截图和日志仅保留在本机 data/，不提交配置、账号、令牌或业务数据库。
