# 功能关联与本轮执行清单

本报告针对已批准方案的 43 项，不包含用户明确排除的功能。历史原文、26 张存档截图和工具索引仅留本地 `data/review-20261030`，不随仓库发布。

## 关键调用关系

- 网页 / QQ → Companion → 有界会话队列 → prompt / 记忆 → DeepSeek → 流式 / 落库 → 反思 / 压缩 / 交接。
- QQ 入站 → 连接身份 → 主人 / 群 / 访客授权 → 防抖与 ASR / 图片 → 聊天 → 当前账号和开关再次校验 → 投递 / 表情 / 补话。
- 自动日程 → 上海时间、次数和本地费用闸 → 生成 → 发送前重新检查 → 平台回执 → 幂等状态 / 台账 / 活动。
- 小红书全部操作 → 可重入、有界浏览器队列 → 当前登录 / 目标会话或确认稿件 → 冷却 / 开关 / 配额 → 发送证据。状态轮询忙碌时读缓存，不抢编辑器。
- Windows 启动 / 停止 → 当前脚本目录 → 本项目可执行文件 / Node 入口匹配；不按端口或全机进程名终止。

## 必须如实保留的限制

- SenseVoice 绑定没有可靠的显式释放接口，保留 `releaseSupported=false`，不宣称内存已被主动释放。
- 真实平台页面可能变化；识别失败是可见错误，不以模拟回归冒充再次真机发布。
- 主人小红书私信的新稳定绑定须用户点击一次；没有可靠消息 ID / 方向时保持不发送。
- 旧 QQ 空间内容的删除没有本轮授权，不执行。用户明确不做的扩展功能不排入任务。
- 在线模型调用和真实公开动作未作为自动测试执行；本机语音往返与模拟平台回归分别报告。

最终测试结果以 [VERIFICATION.md](VERIFICATION.md) 为准，不以本表或历史报告的“已完成”代替验收。
