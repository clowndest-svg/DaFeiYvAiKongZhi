## 本轮实际浏览器交互

不是只启动服务器或检查内部函数：使用独立临时服务、独立 Chromium profile 和模拟模型实际执行：

1. 密码登录与加载控制台；
2. 发送普通聊天，收到流式完成回复；
3. 生成中途停止，随后再发送，新消息不被旧刷新覆盖；
4. 设置修改保留 4.5 秒，保存与重读；每日主动上限 0 保持为 0；
5. 添加记忆并在页面看到，生成动态草稿并在列表看到；
6. 逐页切换桌面/平板/窄屏，检查溢出并保存实际渲染截图。

截图只含隔离测试数据，存于本地 `data/browser-verification/`，已通过会话交付，不上传私密生产截图。浏览器工具的自动安全判定曾超时，最终由本机 Chromium 的可重复端到端测试完成交互验收。

## 关键回归证据

新测试曾在旧实现上准确复现并失败，修复后通过：

- Cookie `constructor` 等继承属性不能被认作登录会话；
- 匿名不能读取草稿截图，跨站副作用不能执行，损坏 URL 不悬挂；
- SAPI 文字只作为数据，DNS 私网/映射 IPv6 与超限下载被拦；
- 公开与群聊/访客 prompt 不出现私人哨兵；标点/全角文字不能绕过照搬检测；
- “不要发说说”、引用和模糊索图不触发空间发布；不同 WS 身份不串号；
- 错误 Cookie 不覆盖有效账号，已发布状态不回退，未知回执不重发；
- 每日主动上限 0、当天发布时间、未知余额下的日预算和跨午夜惦记均正确；
- 普通费用只记一次，半截流不当完成且记估算台账；停止及时取消；
- 当前编辑器被改时不发布，同名私信不足以认主，浏览器嵌套调用不死锁；
- 群聊/访客索图拿不到主人教的私人图片与 mface；改绑取消旧任务；
- WAL 数据进入一致性备份，字面 KV 前缀不误删其他键，其他项目进程不被匹配为本项目。
