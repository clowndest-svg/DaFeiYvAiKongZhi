# 主人聊天工具交付与验收

日期为 2026-11-11，时间按 UTC+8 记录。

QQ 主人私聊和已登录的网页聊天现在能调用实际工具。截图中的需求已经接入聊天回复、附件展示、社交记录和任务回执。

## 使用

在设置的“界面与系统”打开“主人聊天工具”。桌面操作和源码修改各有独立开关。新安装默认关闭，这台机器按主人本轮授权开启。每轮默认最多 12 步，可调至 30 步，任务执行有三分钟截止时间。

可以直接说下面这些话。

- “去看看推特”，或“在推特搜一下指定关键词”。
- “你今天看了什么抖音”，或“去刷一条抖音”。
- “看看 QQ 空间”。
- “把电脑截图发给我”，或在网页聊天里要求返回截图。
- “把 assets/avatar.png 这张图片发给我”。现有图片文件由主人明确提供路径，工具生成的截图会自动附上。
- “打开记事本，输入你好”。已打开的窗口支持聚焦、点击、滚动、输入和组合键。
- “看看 src/chat.js”，或要求读取具体行数。
- “修改指定项目文件的某段内容”，或按修改回执 ID 恢复。
- “开启推特自动浏览”。此入口开启只读模式，按已有时间与费用条件调度。
- 执行中说“停止任务”，QQ 会取消后续步骤。网页可用停止按钮取消。

源码工具可访问 src、web、tools、tests、公开文档、公开默认配置及 package 清单。修改必须基于刚读取的哈希和唯一原文，备份保存在本机 data/source-edits。JS、JSON、Python 和 PowerShell 修改会检查语法，Python 检查依赖本机 Python。服务端代码修改后需要重启加载，回执会说明这一点。

## 执行与反馈

模型通过函数调用请求工具，执行器逐步核对当前身份、开关、步数和费用条件。主人身份由 QQ 通道或控制台认证传入。群聊与访客没有这组工具。

回执同时进入当轮回复和历史消息。相同 QQ 入站消息重放时复用已保存的执行结果，进程中断留下的任务要求核对状态，避免重复修改、点击和发送。

截图作为网页消息附件显示。QQ 任务完成后发送最后一张所需截图，保留发送回执，观察过程中的多次截图不会逐张刷屏。输入动作须匹配当前前台窗口，Windows 拒绝聚焦或输入时按实际错误返回。

聊天和主动消息能读取最近 48 小时的 X 活动、抖音理解笔记及当前能力条件。抖音理解使用画面帧和页面文字，尚未分析音轨。X 只读自动浏览只访问页面并记录内容，付费自动任务继续受余额和日上限约束。

抖音精选页实际使用 div 卡片。本轮补上打开卡片并从 modal_id 核实视频 ID 的流程，选取已加载的播放器采帧，避免把占位 video 当作正在播放的视频。

## 当前运行条件与回退

本机开启主人工具、桌面操作、源码修改、X 只读自动浏览和抖音自动浏览。余额低于现有 5 元阈值时，语音和付费自动任务仍暂停，手动请求按硬熔断与每日上限判断。平台登录、验证和网络状态以实时回执为准。

关闭主人工具开关可立即停用后续工具调用。源码单项回退使用修改回执。整轮代码回退应切回上一版代码并重启服务，设置备份保存在本机 owner-tools-release-backup。当前聊天数据库继续保留，避免用旧备份覆盖新聊天。
