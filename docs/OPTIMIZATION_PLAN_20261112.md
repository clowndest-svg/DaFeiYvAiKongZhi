# 主人任务与跨平台理解优化方案

2026-11-12，基线提交 8be59a9。

## 目标与验收

| 工作项 | 实施内容 | 完成判据 |
| --- | --- | --- |
| 抖音音轨 | 浏览器采集有限长度的视频音轨，本地 ASR 转写，与画面和页面文字联合理解；记录采样起止和失败原因 | 真实音频样本转写可核对，浏览器采集与取消用例通过；无法取得音轨时保留明确状态 |
| QQ 空间 | 核对主接口响应，持久化读取来源与退避；区分兼容读取、过期认证和未识别响应 | 成功的兼容读取显示来源与时间，失败保留缓存，服务重启不会清空退避 |
| 任务进度 | 保存开始、执行步骤、结果、取消和中断状态；控制台提供最近任务与取消操作 | 重启后可查历史，同一 QQ 消息去重；结果未知的步骤先核对 |
| 费用与能力 | 简单状态、截图和明确源码读取减少规划模型请求；状态细分免费读取与付费自动动作 | 保持费用上限，确定的本机命令可直接执行，失败原因与实际回执一致 |
| 输入与恢复 | 修复流式 UTF-8 解码、图片交付、源码文本编码与取消边界 | 相关回归通过，不产生重复发送或过期账号写入 |

## 实施流程

1. 核对当前代码、运行状态、ASR 和平台响应，保存实施前快照。
2. 分项实现，先运行针对实际回归风险的隔离用例，再进行本机专项验证。
3. 更新 README、设置界面与验收记录。
4. 串行执行 npm run check、npm test、npm run test:browser。
5. 排空已有任务后重载本机服务，核对 QQ 连接、机器人身份和新功能。
6. 检查提交内容，提交推送当前分支，等待远端 Node 22/24 CI 完成并核对 SHA。

音轨采用有限采样，报告实际覆盖范围。平台登录验证、限流与手机端实收按真实证据记录。费用保护继续按现有设置执行。
